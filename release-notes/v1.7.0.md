# EasySub Studio v1.7.0 · 全新界面、所见即所得预览与稳定性大修

这一版把界面从头重做了一遍，v1.6.0 及之前的所有功能都还在，一键功能集中放在台词列表上方和顶栏。

### 界面

- **全新设计**：浅色 / 深色 / 跟随系统三种主题，四种氛围色；标题栏、窗口图标、字体统一。
- **命令面板 `Ctrl+K`**：输入几个字就能找到任意功能、模板或某一句台词。
- **画面里直接拖字幕**调整上下位置；专注模式只留画面和时间轴。
- **时间轴重写**：时间重叠的字幕自动分轨显示，不再叠在一起；缩放、拖动、吸附更顺手。
- **行宽尺**：选中一句，立刻看到它占画面多宽、会不会折行。
- **质量筛选**：缺译、过短、过长、时间重叠一键筛出。
- **长片流畅**：3000 句字幕滚动、输入、播放保持满帧。

### 更准

- **预览与导出一致**：按 libass 的字体规则计算，字号和位置与导出的 ASS 对得上（旧版预览大约偏大 31%）。
- 中文输入法选词时按回车不会误触发；替换内容里的 `$&` 等字符按原文处理。

### 更稳

- AI 听写、翻译、精修运行期间你改过的内容**不会被结果覆盖**，结果会先放在顶栏等你确认。
- 上次的草稿不会被新的自动暂存冲掉，恢复后也不会被同名字幕替换。
- 快速连续打开多个视频、启动较慢的机器、设置同时写入等情况下的多处错误已修复。
- 视频和字幕可以一起拖进窗口；工程文件会连同样式一起恢复。

### 包含此前版本的功能

- v1.5.0：一键双语精修向导、断句孤行修复、听障音效清洗。
- v1.6.0：三阶段 AI 翻译、6 套人设、平台快填、连通性测试、配置自动保存。

**已知限制**：MPEG-2 编码的 AVI 无法在窗口内预览画面，会自动切换为纯时间轴模式，字幕编辑和导出不受影响。
