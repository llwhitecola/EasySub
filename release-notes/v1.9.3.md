# EasySub Studio v1.9.3 · VSFilterMod 与歌词 SUP 改进

- 「蓝光 SUP 压制」新增 **VSFilterMod · AviSynth+** 渲染引擎。编辑器字幕和批量 ASS 转换均可使用，默认引擎仍为 FFmpeg · libass。
- 改善 VSFilterMod 输出的 SUP 调色板，保留相近颜色间的渐变层次。已回读验证包含多行歌词的四角渐变。
- VSFilterMod 导出时会提示本机缺失的字体，方便确认输出是否用了替代字形。

使用 VSFilterMod 需要安装与 FFmpeg 位数一致的 AviSynth+，并在压制窗口选择同位数的 VSFilterMod 插件。FFmpeg 需支持 AviSynth 输入。SUP 按字幕区间输出静态画面。
